## ✨ Features

* 🏢 **Multiple Workspaces**
  Create and manage multiple workspaces with separate teams and projects.

* 📁 **Project Management**
  Organize projects, assign members, and track overall progress.

* ✅ **Task Management**
  Create tasks, assign users, set deadlines, and update status.

* 📊 **Analytics Dashboard**
  Get insights like completion rate, team performance, and project stats.

* 👥 **User Management**
  Invite members, assign roles, and manage access.

* 🔐 **Authentication System** 
  Secure login and user sessions.

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/collabrix.git
cd collabrix
```

### 2️⃣ Install dependencies

#### Client

```bash
cd client
npm install
```

#### Server

```bash
cd server
npm install
```

---

### 3️⃣ Run the project

#### Start backend

```bash
cd server
npm run dev
```

#### Start frontend

```bash
cd client
npm run dev
```

---

### 4️⃣ Open in browser

```
http://localhost:5173
```
